## Exercise

Q1. What is the difference between handling an API error with component state and handling it through a route error boundary?
A1. API errors with component state are not route level errors. So, it cannot be catched via an error boundary but if an API error occurrs in the loader or action function of a route then it will get caught by an error boundary.
Feedback:
You wrote that an API error handled through component state cannot be caught by an error boundary.

The distinction is not simply whether an error originates from an API.

For example:
```
try {
  const response = await fetch('/api/products');
} catch (error) {
  setError('Unable to load products');
}
```

Here, the component catches the error and stores it in state. Nothing is thrown to a route error boundary.

But if a component subsequently throws an error during rendering, the route error boundary can catch that rendering error.

The key distinction is whether the error is handled locally, thrown during rendering, or thrown through React Router's loader/action lifecycle.

Q2. If ProductDetails has its own ErrorBoundary, will an error thrown during its rendering reach the root error boundary?
A2. No because the nearest ErrorBoundary takes the precedence over the other ErrorBoundaries defined.

Q3. What does useRouteError() return?
A3. useRouteError() returns the error object of the error appeared at a route. So we can use it in the compnent file of ErrorBoundary to find the exact error and it's details.

Q4. Why should we use isRouteErrorResponse() before accessing error.status?
A4. To find out if that error is generated by Response of an API which is called in loader or action or not.

Q5. Will a route error boundary catch an error thrown directly inside an ordinary button's onClick handler? Why?
A5. No because that is an error that is generated by the button click and not by the rendering of the component.

Q6. Suppose ProductDetails has no error boundary, but ProductsLayout does. Which boundary handles a rendering error in ProductDetails, and what happens to the UI beneath that boundary?
A6. Then ProductsLayout error boundary will handle rendering errors in ProductDetails. The ProductsLayout component will be replaced with the ErrorBoundary component.

## DataRoutes.tsx

```
import { createBrowserRouter, Navigate, type LoaderFunctionArgs, type RouteObject } from 'react-router';
import Home from '../pages/Home';
import Products from '../pages/Products';
import Orders from '../pages/Orders';
import PageTemplate from '../pages/PageTemplate';
import ProductsLayout from '../pages/ProductsLayout';
import CreateProduct from '../pages/CreateProduct';
import ProductDetails from '../pages/ProductDetails';
import ProductEdit from '../pages/ProductEdit';
import LegacyProduct from '../pages/LegacyProduct';
import SearchProducts from '../pages/SearchProducts';
import LocationDetails from '../pages/LocationDetails';
import OrderItem from '../pages/OrderItem';
import OfferDetails from '../pages/OfferDetails';
import FileViewer from '../pages/FileViewer';
import NotFound from '../pages/NotFound';
import ProductErrorDemo from '../pages/ProductErrorDemo';
import ProductErrorPage from '../pages/errors/ProductErrorPage';
import AppErrorPage from '../pages/errors/AppErrorPage';

export const routes: RouteObject[] = [
  {
    Component: PageTemplate,
    ErrorBoundary: AppErrorPage,
    children: [
      { path: '/', Component: Home },
      { path: 'old-products', element: <Navigate to='/products' replace /> },
      {
        path: 'products',
        Component: ProductsLayout,
        ErrorBoundary: ProductErrorPage,
        children: [
          { index: true, Component: Products },
          { path: 'new', Component: CreateProduct },
          { path: ':productId', Component: ProductDetails },
          { path: ':productId/edit', Component: ProductEdit },
          {
            path: 'error-demo',
            Component: ProductErrorDemo,
            loader: ({ request }: LoaderFunctionArgs) => {
              const url = new URL(request.url);
              const status = Number(url.searchParams.get('status'));
              if (status === 404) {
                throw new Response('Product does not exist', {
                  status,
                  statusText: 'Product not found',
                });
              } else if (status === 503) {
                throw new Response('Product service not working', {
                  status,
                  statusText: 'Product service unavailable',
                });
              }

              throw new Response('Unexpected product error', {
                status,
                statusText: 'Unexpected product error',
              });
            },
          },
        ],
      },
      { path: 'legacy-product', Component: LegacyProduct },
      {
        path: 'legacy-product-demo',
        element: <LegacyProduct productId='101' />,
      },
      { path: 'search-products', Component: SearchProducts },
      { path: 'location-details', Component: LocationDetails },
      { path: 'orders', Component: Orders },
      { path: 'orders/:orderId/items/:itemId', Component: OrderItem },
      { path: 'offers/:offerId', Component: OfferDetails },
      { path: 'files/*', Component: FileViewer },
      { path: 'old-catalog', element: <Navigate to={'/products'} replace /> },
      { path: '*', Component: NotFound },
    ],
  },
];

export const router = createBrowserRouter(routes);
```

## data-errors.test.tsx

```
import {
  createMemoryRouter,
  RouterProvider,
  type InitialEntry,
} from 'react-router';
import { describe, expect, it } from 'vitest';
import { routes } from '../src/routes/DataRoutes';
import { render, screen } from '@testing-library/react';
import { userEvent } from '@testing-library/user-event';

const renderRoute = (initialEntries: InitialEntry[]) => {
  const router = createMemoryRouter(routes, { initialEntries });
  render(<RouterProvider router={router} />);
  return router;
};

describe('ProductErrorDemo.tsx', () => {
  it("should show message '404 Product not found' when status is 404", async () => {
    const user = userEvent.setup();
    renderRoute(['/products/error-demo?status=404']);
    expect(
      await screen.findByRole('heading', {
        name: '404 Product not found',
        level: 1,
      }),
    ).toBeInTheDocument();
    user.click(screen.getByRole('button', { name: /back/i }));
    expect(await screen.findByRole('heading', { name: 'Products', level: 1 }));
  });

  it("should show message '503 Product service unavailable' when status is 503", async () => {
    renderRoute(['/products/error-demo?status=503']);
    expect(
      await screen.findByRole('heading', {
        name: '503 Product service unavailable',
        level: 1,
      }),
    ).toBeInTheDocument();
  });

  it("should show message 'Something went wrong!' when status is other than 404 and 503", async () => {
    renderRoute(['/products/error-demo?status=599']);
    expect(
      await screen.findByRole('heading', {
        name: '599 Unexpected product error',
        level: 1,
      }),
    ).toBeInTheDocument();
  });

  it('should render /products/101 perfectly after all the changes', async () => {
    const routes = renderRoute(['/products/101']);
    expect(
      await screen.findByRole('heading', { name: 'Product Detail', level: 1 }),
    ).toBeInTheDocument();
    expect(routes.state.location.pathname).toBe('/products/101');
  });
});
```

## ProductErrorPage.tsx

```
import { isRouteErrorResponse, useNavigate, useRouteError } from 'react-router';

const ProductErrorPage = () => {
  const error = useRouteError();
  const navigate = useNavigate();

  const clickHandler = () => {
    navigate('/products');
  };

  const backButton = <button onClick={clickHandler}>Back</button>;

  if (isRouteErrorResponse(error)) {
    return (
      <div>
        <h1>
          {error.status} {error.statusText}
        </h1>
        <p>{error.data}</p>
        {backButton}
      </div>
    );
  }

  return (
    <div>
      <h1>Something went wrong!</h1>
      {backButton}
    </div>
  );
};

export default ProductErrorPage;
```
